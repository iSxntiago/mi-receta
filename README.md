# Proyecto: Recetas familiares

## Descripción

Este proyecto consiste en crear un repositorio en GitHub donde se documenta una receta familiar utilizando Markdown. Su propósito es poner en práctica los conocimientos adquiridos en clase sobre el uso de Git y GitHub.

Durante el desarrollo se realizará la creación y conexión de un repositorio local con uno remoto, la gestión de archivos y el envío de cambios mediante comandos de Git. Adicionalmente, se clonará el repositorio de un compañero de clase para aprender a trabajar con proyectos compartidos.

## Objetivos

- Crear un repositorio local y uno remoto en GitHub.
- Conectar el repositorio local con GitHub.
- Documentar una receta familiar en un archivo Markdown.
- Practicar comandos como `git add`, `git commit` y `git push`.
- Clonar el repositorio de un compañero utilizando `git clone`.
- Comprender los fundamentos del control de versiones y la colaboración.

## Herramientas utilizadas

- Git
- GitHub
- Visual Studio Code
- Markdown
- Terminal Linux

## Aprendizajes

Con este proyecto se busca fortalecer el manejo de Git y GitHub, comprender cómo se sincronizan los repositorios locales y remotos y conocer las bases del trabajo colaborativo mediante el control de versiones.
